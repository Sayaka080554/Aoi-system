# PLAN · 蓄水池（互购净额台账）

> 状态：**v3.25.0 已实装**（2026-10-14）。先行演示 `demo/reservoir-demo/`（commit 0be295c/57284af/a685943），
> 六项口径 2026-10-13 提出当日拍板，第七项「结算即标记」与币种模型修正（跨币种参考净额）2026-10-14 补拍板后实装。

## 一、定位

和日本/韩国代购联系人**互买谷子**的挂账本：我帮 TA 买（TA 欠我）、TA 帮我买（我欠 TA），每笔都直接转账既麻烦又扣
手续费（PayPal/跨境汇款）——改为账面挂账、双向滚动累计，只看净额，攒到合适时机一次结清（转账或以货抵账）。
订单计入蓄水池两侧，实时看各币种净额与「到底谁欠谁多少」的参考净额。

## 二、拍板口径（七项）

1. **一池多对手方**：转账通常由一人完成，订单来自多人多活动，池内按购买人小计。
2. **手工账同步新建订单**：邮费/佣金等不在订单里的钱手工记一笔时，同步新建真实订单
   （备注前缀「蓄水池手工账」），可在订单管理排查。
3. **币种模型（一单一次计入）**：每笔订单按记账币种（外币原价 `priceOrig+currency` 或人民币 `price`）计入
   **唯一币种桶**，桶内两侧相抵得该币净额；另设**人民币视图**（各侧已转化人民币合计，缺转化留空+提醒）与
   **参考净额**（按池内参考汇率把各币种活水统一折算人民币的单一答案，汇率可编辑、仅供决策不改账本）。
   跨币种池「到底谁欠谁多少」以参考净额为准（用户实测场景：我买 15 刀记 105 人民币、TA 买 10 刀记 1400 円 →
   美元桶净额对方欠 5 刀 + 人民币视图单侧 105 + 参考净额对方欠 ≈¥35；TA 侧改记 1400 円口径不变）。
4. **结算流水**：转账/换货抵账记一笔（方向=对方转我方冲抵TA欠 / 我方转对方冲抵我欠），净额即时冲抵。
5. **结算即标记**：结算可勾选池内订单一并标记「已结算」——移出活水净额、行置灰锁定、订单管理里该单不可重复计入；
   删除结算流水自动取消标记、金额回活水；纯转账（不勾订单）照旧只冲抵不标记。
6. **金额自动跟随订单改价**：池内条目只引用 `orderId`，合计实时读订单现价；订单删除保留快照灰显（同 demo 口径）。
7. **仅管理员可见**：工具组导航，团员端无入口；导出对账单放二期。

## 三、数据模型（blob 新键 `d.reservoirs`，零 schema 改动）

```
d.reservoirs = [{
  id, name, sideA, sideB,          // 池名与两侧文案（建池可改）
  rates: { jpy: 0.048, ... },      // 参考汇率（可编辑；缺省用 DEFAULT_RATES，cny 恒 1）
  entries: [{ id, orderId, side: 'A'|'B', addedAt,
              settledAt?, settlementId? }],           // 结算标记（settledAt 有值=已结算）
  settlements: [{ id, direction: 'them2us'|'us2them', currency, amount, date, note,
                  entryIds?: [...] }]                  // 关联订单的结算不进净额公式（效果=订单移出活水）
}]
```

净额公式（每记账币种）：`净额 = 活水A − 活水B + 对方转我方 − 我方转对方`（活水=未结算条目）；
`参考净额 = Σ 各币种净额 × 参考汇率`。

## 四、页面与交互

- **导航**：工具组「蓄水池」（计算器/限购计划与 PCO 目录之间）。
- **计入**：订单管理勾选 → 工具栏「计入蓄水池」→ 弹层选池+侧向 → 计入（一单只入一池，已在池中自动跳过，
  30 秒撤销，undo 快照）；池卡「勾选订单计入」跳转订单管理。
- **池卡**：参考净额（虚线高亮）+ 各币种净额 + 未转化提醒；展开明细 = 币种汇总表（活水/冲抵/净额/已结算）、
  人民币视图行、参考汇率编辑、按购买人小计、两侧明细（勾选结算/改侧/移除）、结算流水（关联列，可删）。
- **手工账 / 结算弹窗**：字段与预填逻辑同 demo（结算按勾选预填方向与金额，可抹零；币种不符仅标记）。

## 五、零干扰与安全

- 只读订单、新增 blob 键：不改订单任何字段、不参与复盘统计/国际费/审批口径、团员端完全无感。
- 全部写路径走 `Aoi.saveTeamData`（乐观锁/失败提示统一）+ `Aoi.undo.arm` 30 秒撤销；展示层 `Aoi.escapeHtml` 全量转义。
